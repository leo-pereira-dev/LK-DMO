# Dungeon Enter Packet Map

Strings encontradas na varredura decompilada relacionadas a entrada/contagem de dungeon:

- `GS2C_NTF_DUNGEON_ENTER_COUNT_LIST`
- `GS2C_NTF_DUNGEON_ENTER_COUNT_UPDATE`
- `sDungeonEnterCountInfo`
- `C2GS_REQ_DUNGEON_RE_ENTER`
- `C2GS_RES_APPROVE_DUNGEON_RE_ENTER`
- `GS2C_DUNGEON_RE_ENTER_RESULT`

Esses pacotes nao montam a janela visual diretamente; eles alimentam estado de contagem/reentrada usado pela tela.
